# 楚河棋社

双人局域网中国象棋。双击 `启动象棋.bat`，保持窗口打开，用浏览器访问窗口显示的本机地址；朋友连接同一 Wi-Fi 后访问窗口列出的局域网地址。创建房间后分享房间号或链接。若朋友无法连接，请确认使用同一网络，并允许 Node.js 通过 Windows 防火墙的专用网络；某些公共 Wi-Fi 会隔离设备。

项目自带 Windows x64 便携 Node.js，首次启动若缺少依赖会尝试联网安装。手动运行：`node-runtime\npm.cmd install`（先将 `node-runtime` 加入 PATH），然后 `node-runtime\node.exe server.js`。运行测试：`node-runtime\node.exe --test`。默认端口 3000，可通过 `PORT` 环境变量修改。

创建者红方先行，双方轮流操作。点击己方棋子后点击目标位置。双方同意可以撤销最近一步；一局结束后双方同意可换边重开。刷新和网络短暂断开后可恢复原席位；断线超过 10 分钟对局结束，不判胜负。房间与棋局仅保存在运行中的服务器内存，重启服务后清空。

走法包含将帅照面和自陷将军限制；将死或无合法走法判负。同一局面且同一方行棋第三次出现时判和，不裁决长将长捉。无登录、计时、观战或 AI。仅供可信局域网使用，未针对公网部署进行安全加固。
